cf-sensor-afe is a chipIgnite reference: a high-Z sensor, on-die conditioning, and a 12-bit code to firmware — on the same die as the RISC-V CPU. That is a user project, not an eval board full of analog chips.

02CF_BUF_HIZOn-die buffer. The sensor never drives a 50 Ω trace.
03CF_ADC_SAR1212-bit SAR at 1 Msps, referenced from an on-die bandgap
04FirmwareWishbone CSR. 12-bit code on UART.
